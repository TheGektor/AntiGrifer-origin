# AntiGriefSystem (AGS) 🛡️

**AntiGriefSystem v3** — модульный античит-плагин защиты от гриферства для серверов Minecraft (Paper 1.21.x).

Плагин строится вокруг многоуровневой **системы доверия (Trust Tier)**, которая автоматически повышает права игрока по мере набора времени на сервере. Параллельно работает пайплайн обнаружения, который перехватывает подозрительные действия, записывает их в Replay-буфер, собирает метрики и — при необходимости — отправляет алерты администраторам и в Discord.

---

## ✨ Возможности

### 🔐 Система доверия (Trust Tiers)

Каждый игрок автоматически получает уровень доверия на основе наигранного времени:

| Tier | Название | По умолчанию |
|:----:|:---------|:-------------|
| 0 | Недоверенный | До 60 мин |
| 1 | Уровень 1 (Огнеопасно) | 60 – 120 мин |
| 2 | Уровень 2 (Взрывоопасно) | 120 – 240 мин |
| 3 | Уровень 3 (Редстоун) | 240+ мин |

Администратор может вручную переопределить уровень доверия любому игроку командой `/antigrifer trust`.

### 🔍 Модули обнаружения

| Модуль | Что проверяет |
|:-------|:--------------|
| `LavaPlaceCheck` | Размещение лавы игроком ниже Tier 1 |
| `FireUseCheck` | Использование огня (кремний, огниво) ниже Tier 1 |
| `ExplosiveCheck` | Установка TNT и кристаллов ниже Tier 2 |
| `RedstoneGriefCheck` | Активация диспенсеров/дропперов с запрещёнными предметами ниже Tier 3 |

### ⚙️ Движки ядра

- **ActionPipeline** — единый пайплайн обработки всех действий игроков через чеки.
- **DetectionEngine** — запускает Check-цепочки и агрегирует результаты.
- **PatternEngine** — анализ поведенческих паттернов.
- **BehaviorEngine** — поведенческая аналитика (TrustModule).
- **SimulationEngine** — симуляция и предсказание действий.
- **RateLimitEngine** — ограничение частоты действий (rate limiting).
- **RuleEngine** — кастомизируемые правила обработки.
- **MetricsEngine** — сбор и отображение статистики плагина.
- **ReplayEngine** — буфер последних действий каждого игрока (всегда включён).
- **DebugService** — режим живой отладки для администраторов.

### 📢 Discord-интеграция (Forum Threads)

- При первом алерте игрока создаётся **тред в Forum-канале** Discord.
- Все последующие алерты того же игрока отправляются **в уже существующий тред**.
- Команды `ack` и `tp` обновляют тред с информацией о том, кто обработал инцидент.
- При закрытии (`ack`) тред-ID сбрасывается: следующий алерт откроет новый тред.

### 🗄️ Хранилище

Данные игроков (плейтайм, Tier, нарушения, флаги) хранятся в **YAML-файлах** в папке плагина. Данные сохраняются при отключении и восстанавливаются при подключении.

## 📥 Установка

1. Скачайте последний `AntiGriefSystem-x.x.x.jar` со страницы [Releases](https://github.com/your-repo/AntiGriefSystem/releases).
2. Поместите JAR в папку `plugins/` сервера.
3. Перезапустите сервер — будет создан конфиг по умолчанию.
4. Отредактируйте `plugins/AntiGriefSystem/config.yml`.
5. *(Опционально)* Настройте Discord-вебхук в конфиге и перезапустите.

## 💬 Команды и права

Все команды доступны только игрокам с правом **`antigrifer.admin`**.

Главная команда: `/antigrifer` (или `/ag`)

| Команда | Описание |
|:--------|:---------|
| `/antigrifer help` | Список всех команд |
| `/antigrifer trust <игрок> [0\|1\|2\|3\|auto]` | Просмотр или ручное изменение Tier игрока |
| `/antigrifer playtime <игрок>` | Плейтайм, текущий Tier и время до следующего уровня |
| `/antigrifer alerts` | Список активных (необработанных) алертов с кнопками |
| `/antigrifer ack <игрок>` | Закрыть алерт игрока (notify в Discord) |
| `/antigrifer tp <игрок>` | Телепортироваться к игроку и закрыть алерт |
| `/antigrifer debug [игрок]` | Подробный дебаг-профиль игрока |
| `/antigrifer module list` | Список зарегистрированных модулей |
| `/antigrifer module enable <имя>` | Включить модуль |
| `/antigrifer module disable <имя>` | Отключить модуль |
| `/antigrifer module reload <имя>` | Горячая перезагрузка модуля |
| `/antigrifer metrics` | Статистика плагина (счётчики движков) |
| `/antigrifer replay view <игрок>` | Последние 15 действий игрока |
| `/antigrifer replay export <игрок>` | Экспорт полного буфера действий в лог сервера |
| `/antigrifer reload` | Перезагрузить конфигурацию |

> Все команды поддерживают **Tab-дополнение** — имена игроков, субкоманды и модули подсвечиваются автоматически.

## ⚙️ Конфигурация

### `config.yml`

```yaml
# ─── Хранилище ───────────────────────────────────────────────────────────────
storage:
  type: yaml   # yaml (по умолчанию)

# ─── Система доверия (Trust Tiers) ────────────────────────────────────────────
trust:
  tier1-minutes: 60     # Tier 0 → Tier 1 (Огнеопасно)
  tier2-minutes: 120    # Tier 1 → Tier 2 (Взрывоопасно)
  tier3-minutes: 240    # Tier 2 → Tier 3 (Редстоун)

  # Материалы, заблокированные ниже Tier 1
  fire-materials:
    - FLINT_AND_STEEL
    - FIRE_CHARGE
    - LAVA_BUCKET

  # Материалы, заблокированные ниже Tier 2
  explosive-materials:
    - TNT
    - END_CRYSTAL

  # Материалы в диспенсере, заблокированные ниже Tier 3
  redstone-materials:
    - TNT
    - LAVA_BUCKET

# ─── Discord (опционально) ────────────────────────────────────────────────────
discord:
  enabled: false
  webhook_url: "https://discord.com/api/webhooks/..."
  forum_channel: true   # true = Forum-канал (треды), false = обычный текстовый

# ─── Сообщения ────────────────────────────────────────────────────────────────
messages:
  no_permission_lava:    "&cУ вас недостаточно доверия для размещения лавы! (Нужно 60 мин)"
  no_permission_fire:    "&cВам нельзя использовать огонь. (Нужно 60 мин)"
  no_permission_tnt:     "&cВам нельзя размещать TNT. (Нужно 120 мин)"
  no_permission_redstone:"&cВам нельзя использовать этот механизм. (Нужно 240 мин)"
```

## 🏗️ Архитектура проекта

Проект разделён на несколько Gradle-подмодулей:

```
source/
├── api/               # Публичные интерфейсы (AGModule, Check, PlayerContext, …)
├── common/            # Общие типы (ActionInfo, ActionType, …)
├── core/              # Ядро: движки, пайплайн, доверие, хранилище, алерты
├── modules/
│   ├── detection/     # Модуль детекции (LavaPlace, FireUse, Explosive, Redstone)
│   └── trust/         # Модуль доверия (поведенческая аналитика)
└── platform-paper/    # Paper-платформа: плагин, адаптер, Discord, команды
```

Для добавления нового чека нужно реализовать интерфейс `Check` и зарегистрировать его через `DetectionModule`.

## 🏗️ Сборка из исходников

Требуется **JDK 21**.

```sh
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/AntiGriefSystem.git
cd AntiGriefSystem/source

# 2. Соберите проект
./gradlew build

# 3. Готовый JAR будет в:
#    platform-paper/build/libs/AntiGriefSystem-<version>.jar
```

Для локального тестового сервера (Paper 1.21.x, автоматическая загрузка):
```sh
./gradlew runServer
```
